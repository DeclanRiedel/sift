# Icon provenance

Application icons in this directory are vendored from
[Qlementine Icons](https://github.com/oclero/qlementine-icons#author), authored by
Olivier Cléro and distributed under the MIT license. The vendored source is
commit `e2ad8c109d245f11b3fcb2c39f8b26aeee87ff50`; see
`LICENSE.qlementine-icons`.

The upstream black fills were changed to `currentColor` so Sift's semantic
theme controls icon colour. `fallback.svg` is a Sift-owned red `{!}` mark and
must be used when Qlementine has no appropriate semantic icon.
