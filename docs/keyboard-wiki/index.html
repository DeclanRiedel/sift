Sift command language

Local Vim motions manipulate focused content. Leader sequences perform IDE actions. Press : from normal mode for the searchable command palette.

Spaceleader in Vim/UI normal mode
Ctrl+Kfallback leader
Escreturn toward normal mode

Mode model

NORMAL

Navigate surfaces and enter leader commands.

INSERT

Edit SQL, text fields, or cell values.

VISUAL

Select text, cells, rows, or objects.

COMMAND

Resolve leader sequences or search commands.

Esc cancels one layer: prompt → component → normal. Literal Space and colon remain available while inserting text.
