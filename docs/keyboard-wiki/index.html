Sift keyboard defaults

Local Vim keys control focused content. Leader commands control the IDE. Press : in normal mode to open the command palette.

Leader: Space in Vim/UI normal mode or Ctrl+K as fallback. Press Esc to cancel or return toward normal mode.

The footer keeps SQL mode/input separate from the IDE command sequence. After leader, IDE keys never replay into SQL; take your time and press Esc to cancel.

Open Keymaps to edit bindings in the compact table, or use Open JSON to edit keymaps.json. Empty bindings disable commands; saved changes apply immediately.

Pane focus

Drag a dock or results divider within 48px of its outer edge to hide it. Reopen docks with their usual toggle; restore results with the tab-row Show results button or <leader> g r (Focus Query Results). Releasing a split divider near either edge merges that side's tabs into the neighboring pane, preserving unsaved edits and query results.

Results

Select a range of editable table cells, then press Enter or i to edit their text together. Each cell keeps its own value; edits follow the caret's character distance from the end of each value. Press Enter to stage all changes or Esc to discard the current edits. Use :w to apply staged table changes.
